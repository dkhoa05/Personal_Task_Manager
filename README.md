# Personal Task Manager 🗂️

## Mô tả dự án
**Personal Task Manager** là một ứng dụng quản lý công việc cá nhân, cho phép người dùng:
- Thêm, cập nhật, xóa nhiệm vụ
- Phân loại theo trạng thái (chưa làm, đang làm, hoàn thành)
- Theo dõi tiến độ công việc
- Giao diện thân thiện, dễ sử dụng

## Tính năng chính
- 📝 Tạo mới nhiệm vụ với tiêu đề, mô tả, hạn hoàn thành
- 📋 Hiển thị danh sách công việc theo trạng thái
- ✅ Đánh dấu hoàn thành / chỉnh sửa / xóa nhiệm vụ
- 🔍 Tìm kiếm và lọc công việc theo ngày, trạng thái
